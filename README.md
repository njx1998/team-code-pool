# 组队 · 组队码互助池小程序

微信原生小程序，基于微信云开发（云数据库）。用户提交组队码进入互助池，其他人复制领取，支持举报下架与统计展示。

## 功能特性

- **发码**：8/9 位数字组队码提交，前端校验 + 云数据库持久化
- **互助池**：最近 20 条码实时展示，「全部 / 可用 / 已用」过滤，可用码自动置顶
- **复制领取**：完整码弹窗 + 剪贴板写入，复制即标记已用
- **举报**：选理由上报，举报数原子自增，满 3 次自动下架
- **统计条**：今日发码人数 / 可用数量 / 累计提交数，均为云数据库实时计数
- **其他**：下拉刷新、转发分享、空态引导

## 运行方式

1. 打开微信开发者工具，导入本仓库根目录
2. `app.js` 中 `wx.cloud.init` 的 `env` 替换为自己的云环境 ID
3. 云开发控制台创建集合 `codes`，权限设为自定义规则：

```json
{
  "read": true,
  "write": true
}
```

4. 编译运行

## 数据结构

集合 `codes`，一条码一个文档：

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 完整组队码 |
| `status` | string | `available` 可用 / `used` 已用 / `removed` 已下架 |
| `reports` | number | 累计举报次数，`cmd.inc(1)` 原子自增 |
| `createdAt` | date | 提交时间（服务端时间 `serverDate`） |

写入时自动附带 `_openid`（提交者身份）。

## 服务端规划

以下校验需通过云函数在服务端可信环境完成：

- 提交频控（一人一天最多几条）与黑名单校验
- 同一用户对同一码限报一次
- 来源 IP 获取与记录
- 举报满阈值后对提交者扣信用分、限制发码
